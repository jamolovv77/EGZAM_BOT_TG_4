📦 ТЗ №9 — Mini Shop Bot (Боти мағозаи хурд)
Мақсади проект:

Мо бояд як Telegram Bot созем, ки дар он одамон маҳсулотро бинанд, харид кунанд ва таърихи харидҳои худро бинанд.

Масалан:
- Як нафар маҳсулот илова мекунад.
- Дигар одамон маҳсулотро мебинанд.
- Агар маҳсулот мавҷуд бошад, онро мехаранд.
- Бот миқдори маҳсулотро кам мекунад.
- Харидҳо дар базаи маълумот нигоҳ дошта мешаванд.
Пардохти ҳақиқӣ лозим нест.
1. Командаҳои асосӣ
Команда	Вазифааш
/start	Оғози бот ва нишон додани командаҳо
/help	Фаҳмондани тарзи истифодаи бот
/add_product	Илова кардани маҳсулоти нав
/catalog	Нишон додани ҳамаи маҳсулот
/product	Нишон додани маълумоти як маҳсулот
/my_orders	Нишон додани таърихи харидҳои ман
/sales	Нишон додани чанд дона маҳсулот фурӯхта шудааст
/cancel	Қатъ кардани илова кардани маҳсулот

Мисол:

/product 5

Яъне маълумоти маҳсулоте, ки ID-и он 5 аст, нишон дода мешавад.

/sales 5

Яъне чанд дона маҳсулоти рақами 5 фурӯхта шудааст.

Муҳим: командаи /sales танҳо барои соҳиби ҳамон маҳсулот кор мекунад.
2. Илова кардани маҳсулот бо FSM
Вақте ки мо /add_product менависем, бот бояд саволҳоро як-як диҳад.

Мисол:
Bot

Номи маҳсулотро нависед:

User: Телефон

Bot: Категорияи маҳсулотро нависед:

User: Electronics

Bot: Нархро бо сомонӣ нависед:

User: 2500c

Bot: Миқдори маҳсулотро нависед:

User: 10

Bot: Расми маҳсулотро фиристед:

User: 📷 Расм мефиристад

Маҳсулот илова шуд
Bot: Маҳсулот бо ID: 1 илова карда шуд! 🎉

Яъне FSM панҷ қадам дорад:
1. Номи маҳсулот.
2. Категория.
3. Нарх.
4. Миқдор.
5. Расм.
Қоидаҳо:
- Нарх бояд аз 0 калон бошад.
- Миқдор бояд адади бутун бошад ва аз 0 кам набошад.
- Номи маҳсулот ва категория холӣ набошанд.
- Агар маълумоти нодуруст диҳем, бот бояд хатогиро фаҳмонад ва ҳамон саволро такрор кунад.
Пас аз қадами охирин маҳсулот ба база сабт мешавад. Дигар тасдиқи иловагӣ лозим нест.
3. Inline Keyboard (тугмаҳо)
Дар назди ҳар маҳсулот бояд тугмаҳо бошанд.









📱 Телефон

Категория: Electronics

Нарх: 2500 сомонӣ

Миқдор: 10 дона
Подробнее

Намунаи намуди тугмаҳо дар бот.
Маънои тугмаҳо:
- Подробнее — маълумоти пурраи маҳсулотро нишон медиҳад.
- 🛒 Купить 1 шт. — як дона маҳсулотро мехарад.
Вақте ки одам тугмаи харидро пахш мекунад:
- Миқдори маҳсулот як дона кам мешавад.
- Харид дар база сабт мешавад.
Агар маҳсулот тамом шуда бошад, харид иҷозат дода намешавад.
4. Database (Базаи маълумот)
Дар ин проект ду таблица месозем.

1. products — маҳсулот
Column	Маъно
id	Рақами маҳсулот
owner_id	ID-и соҳиби маҳсулот
title	Номи маҳсулот
category	Категория
price	Нарх
stock	Миқдори маҳсулот
photo_file_id	ID-и расм

2. orders — харидҳо
Column	Маъно
id	Рақами харид
user_id	ID-и харидор
product_id	ID-и маҳсулоти харидашуда
purchase_price	Нарх дар вақти харид
purchased_at	Санаи харид

Яъне products маълумоти маҳсулотҳоро нигоҳ медорад, orders бошад маълумоти харидҳоро.
5. Қоидаҳои муҳими харид
Ин қисмро хуб фаҳмидан лозим аст.
1. Агар миқдори маҳсулот 0 бошад, харид кардан мумкин нест.
2. Соҳиби маҳсулот маҳсулоти худашро харида наметавонад.
3. Ҳар як хариди муваффақ миқдорро танҳо 1 дона кам мекунад.
4. Ҳар як харид дар таблицаи orders сабт мешавад.
5. Агар маҳсулот тамом шуда бошад, тугмаи кӯҳна ҳам набояд харидро иҷро кунад.
6. Як маҳсулотро чанд маротиба харидан мумкин аст, агар миқдораш бошад.
Як нуқтаи муҳим: кам кардани миқдор ва сабт кардани харид бояд дар як Transaction иҷро шаванд. Ин барои он аст, ки агар ду нафар якбора охирин маҳсулотро харанд, ҳар ду харид карда натавонанд.
6. Командаҳои иловагӣ
/my_orders

Таърихи харидҳои худи одамро нишон медиҳад.

Масалан:
- Телефон — 2500 сомонӣ — 31.10.2026
- Ноутбук — 5000 сомонӣ — 31.10.2026
Дар ин ҷо бояд JOIN истифода шавад.

/sales 5

Нишон медиҳад, ки маҳсулоти рақами 5 чанд маротиба фурӯхта шудааст.

Дар ин ҷо COUNT истифода мешавад.
7. Талаботи техникӣ
Барои сохтани проект инҳоро истифода мебарем:
Технология	Барои чӣ?
Python	Забони программасозӣ
aiogram 3	Сохтани Telegram Bot
PostgreSQL	Базаи маълумот
asyncpg	Пайваст кардани Python ба PostgreSQL
FSM	Илова кардани маҳсулот қадам ба қадам

Файлҳоро бояд ҷудо кунем:
- main.py — оғоз кардани бот.
- connection.py — пайвастшавӣ ба база.
- services/ — ҳамаи SQL-запросҳо ва кор бо база.
- handlers/ — командаҳо ва коркарди паёмҳои Telegram.
- keyboards/ — тугмаҳо.
- states/ — ҳолатҳои FSM.
8. Бонус (+10 балл)
Агар хоҳӣ, боз як команда илова мекунӣ:

/spending

Ин нишон медиҳад, ки одам дар маҷмӯъ чанд сомонӣ барои харид сарф кардааст.

Барои ин SUM(purchase_price) истифода мешавад.

Агар ҳеҷ чиз нахарида бошад, натиҷа 0 мешавад.
9. Барои супоридан чӣ лозим аст?
Дар охир бояд ин чизҳоро супорӣ:
1. Ҳамаи файлҳои Python.
2. requirements.txt
3. SQL-файли сохтани таблицаҳо.
4. .env.example — намунаи маълумоти пайвастшавӣ, бе парол ва токени ҳақиқӣ.
5. README — дастури кӯтоҳи ба кор даровардани бот.
